# Risk上游感知诊断记录

完整报告在数据根目录 `analysis/risk_layer_diagnosis_20261019/REPORT.md`；检测专项在其 `detector_audit/REPORT.md`。数值来自原epoch5检查点，默认模型未替换，五维标签定义未修改。

当前Risk直接读取8个Radar token及Ego编码，不读取检测框。自写DenseRadarDetector是并行单阶段分支，使用当前帧stride4特征，并通过token均值和Ego获得全局context；它不等同于完整标准YOLO预训练架构。检测loss可沿两路训练共享CNN/时序模块。

36个完整标签风险漏检帧中，35帧至少有一个危险来源的有效Doppler单元；危险来源关联径向速度误差中位数0.0208m/s。37个危险来源目标仅检出20个，另17个都有2m内候选但置信度不足0.5；附近最佳置信度中位数0.331，训练分配候选中心误差中位数0.422m。已检出的20个来源速度误差中位数2.144m/s、未来ADE中位数2.274m；同一20个来源的原始关联径向误差中位数0.0200m/s，检测预测径向误差中位数0.728m/s。

冻结token上的固定MLP探针训练AP0.952–0.972，验证AP0.433–0.498。按训练负例99%分位阈值，原36个漏检只能检出0–3个，验证误报41–60。该探针不是Planner模式评价，不代表模型修复。

原始8×8与CNN2×2线性探针不能直接定位CNN信息损失。把原始输入也池化2×2后验证AP约0.077，低于CNN2×2的0.109–0.116；空间摘要本身已引入显著影响。独立非线性探针也存在train/val差距，因此当前证据支持共享感知栈泛化不足，尚不能单独认定CNN或8-token压缩是唯一根因。

自然训练比例下，距离监督对风险共享参数的平均梯度较大，但危险正例内Pcol3/dmin方向同向。99帧回放中检测objectness在Encoder上的梯度显著大于速度/未来项；漏检组检测/风险总体梯度同向。梯度为当前点局部统计，未包含Planner任务和Adam预条件，不能据此直接修改loss权重。

下一步优先独立验证/训练Grounder，保持Planner冻结，联合检查危险来源召回、置信度、径向/二维速度及未来误差、train/val差距，再验证风险和模式。此训练尚未执行；降低检测阈值的全量误报代价亦未验证。

诊断脚本：`scripts/diagnose_risk_layers.py`、`scripts/audit_detector_risk.py`；测试：`tests/test_risk_layer_diagnosis.py`，4 passed。原始配对训练子集为全部477个Pcol3正例加固定1000个负例，验证1461帧；缓存特征探针及梯度统计覆盖完整6728帧训练集。各阶段输出与缓存精确匹配2938帧，原模型参数/缓冲区和src源码摘要均未改变。

数据解释边界：当前框归属只核对最后一帧；径向速度不能唯一决定二维运动；只使用当前离线缓存，不证明其预处理零延迟因果性；本轮未做完整轨迹或闭环评价。
