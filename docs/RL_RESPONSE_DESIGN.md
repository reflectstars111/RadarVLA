# 第三阶段响应时间微调：当前实现

Stage 1 冻结检测与他车预测；Stage 2 SFT 提供初始规划策略；Stage 3 优化检测报告到有效自车避险的时间，包括共用部署路径实测生成耗时。

实现为独立事件内的多帧执行回放，采用组内独立基线 REINFORCE 与固定 SFT 条件 KL。一次事件只有一个响应计时起点；后续规划按 FIFO 排队并承接已采用动作，安全检查覆盖完整延迟尾段。事件支持既有目标变危险、重新出现和初始危险。漏检、未知覆盖保留在危险响应统计中。

SHORT 原生样条后追加显式有界停车段，规划时域和奖励 GT 时域分离。响应起点由不依赖未来 GT 的轨迹变化计时器记录；目标间距改善、碰撞和切换连续性是独立质量诊断。缺少尾段标注不会抹掉时间或响应时间奖励，已知危险仍处罚。第 0 轮 SFT 参与最佳模型选择。预测与 RL 共用生成／解码计时和执行适配器，HF 重评分保持 dropout 关闭并实际启用梯度检查点。

完整协议、命令、指标定义与局限见 [RESPONSE_RL.md](RESPONSE_RL.md)。初次审查发现与反例见 [审查记录](RESPONSE_RL_REVIEW_20261013.md)；该记录描述修复前状态。

当前不是闭环驾驶仿真：独立事件间没有未记录活动计划的连续状态，事件内观察也不会因动作改变。测试证明代码行为和有限候选策略的学习方向，不证明真实大模型或实车性能。
