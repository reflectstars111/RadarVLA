## 比较边界

- 当前只训练Grounder，不训练LLM，不据此宣称SHORT模式或rollout改善。
- moving-v1排除静止车辆、行人、自行车并重新计算Risk；不能与旧标签结果直接比较或作为静止障碍安全结论。
- 单个配对种子提供初步证据，不能代替多种子统计；不挑选最有利epoch作主要结论。
- 检测阈值0.5、NMS阈值0.3、匹配距离2m固定。50m外未标注区域按原规则忽略，输入仍保留约118m。
- 检测召回须与误报/Precision同时阅读；速度与轨迹误差须说明匹配集合。
- 原生物理指标使用GT位置Hungarian分配；上表检出目标ADE和最终共同检出审计是另一个统计口径。
- 未执行测试集推理；每轮保存完整验证指标、训练时间和峰值分配显存。
