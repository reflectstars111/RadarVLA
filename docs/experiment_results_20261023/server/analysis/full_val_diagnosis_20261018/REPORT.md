## 2. 核心结论

1. 全量 SHORT 召回 **0.3571**，精确率 **0.5263**；真实 SHORT 中 **36** 帧被生成 LONG，**0** 帧无有效模式。
2. 教师要求时刻覆盖 **0.9916**；在相同已覆盖要求时刻上，模型 ADE **1.1295 m**，CV **0.9234 m**，模型−CV **0.2061 m**（负数代表模型误差更小）。
3. 检测 Precision/Recall/F1 = **0.6565/0.3167/0.4273**；TP/FP/FN = **1571/822/3390**。
4. 自车样条初速误差均值 **0.3922 m/s**；这是解析导数与当前观测自车速度的差，不能由坐标误差代替。
5. 2 s 碰撞概率在 0.5 阈值下召回 **0.1750**（7/40）；这是风险头的单独诊断，LLM 的模式并非用该阈值直接路由。
6. areq MAE **0.0741 m/s²**，恒零预测 MAE **0.0490 m/s²**；GT>0 的 46 个有效样本上 MAE **1.2896 m/s²**。低总体均值不足以证明需要制动时的预测可靠。
7. 共享 GPU 上的生成耗时中位数 **3.246 s**，P95 **6.716 s**；反映当前无 KV-cache 的实现与同时运行任务下的实测，不是独占吞吐。

8. 移动组模型/CV ADE为 **1.5226/2.0975 m**，慢行组为 **0.9854/0.4930 m**。总体退化并非所有运动场景一致变差，停止/慢行保持应重点复查。

编码器静止探针：64档位置 bin 不含精确0，0被编码为 0.072243 m。将全零自车未来控制点按当前词表编码/样条解码，SHORT 的初速为 0.3882 m/s、静止ADE为 0.1060 m；LONG 初速为 0.1294 m/s。该探针只展示一种确定性量化误差，不是全数据误差下界。物理loss使用分布期望，生成使用argmax，两条路径也可能产生差异；应结合本轮实际codec结果判断，不能把全部误差归于网络。

全教师要求点的 CV ADE 为 0.9473 m；自由生成覆盖了 8470/8542 个要求点。生成点总 ADE 为 1.1693 m，但其时间覆盖随模式改变，不能单独用于优劣结论。

按 episode 聚类重采样的配对 ADE 差 95% 区间为 [-0.2529, 0.8603] m，使用 10 个 episode、2000 次重采样。该区间只覆盖模型已生成的要求点，不能补偿漏规划时域或数据来源偏差。

## 10. 后续实验顺序

### 按本轮证据确定的优先级

**优先排查Risk估计与条件使用。** 在同一1407帧、46个SHORT的完整标签cohort上，预测Risk的模式召回为10/46，Oracle为44/46。这说明模式输出对Risk条件高度敏感，应先检查风险估计、分量尺度/校准以及Stage2联合更新的影响。Oracle标签分布可能与训练时预测Risk分布不同，此结果不单独证明唯一因果；下一步可做冻结Grounder与联合训练的配对对照，并在同一cohort评价风险质量、模式与规划。

**优先复查停止保持和自由生成误差。** 慢行组free ADE=0.9854 m，codec=0.1101 m，teacher-forcing=0.2467 m；Scenario7_9的free/CV为1.4988/0.0410 m。约0.1m的量化探针误差不足以解释这一级退化。全体free初速误差与codec均值接近，需先复核停驻样本、前序道路/Agent描述与自回归误差，再决定是否改变表示或初速损失；不能直接归因为缺少Ego输入。

**并行定位近距漏检及动态量学习。** 0–10m召回仅约17.2%；在相同1458个有效Doppler匹配上，GT投影MAE约0.501m/s，检测速度投影约1.853m/s，仍有明显模型误差。观测也存在尾部不一致，需要逐例复核而非默认全部标签正确。Qwen描述状态的匹配精确率约20.4%、召回约24.8%，与Grounder任务口径不同，说明生成描述仍需单独治理；不据此替代稠密检测指标。

1. 优先复查漏判 SHORT 的样本，并使用同 cohort Oracle 首 token 结果区分 Risk 估计和模式条件使用问题；尚不能据此认定某个模块是唯一原因。
2. 按 moving/turning/危险样本与 codec、teacher-forcing 对照，决定下一轮是否优先处理样条量化、初速约束、曝光偏差或模式训练分布。每次改动保持固定 val 口径并做单因素对照。
3. 对漏检集中区间做标注覆盖/匹配/回波关联复核，再决定检测训练改动；当前结果不通过调阈值回填成模型改进。
4. 核实 Doppler 双侧解模糊的约0.2 s未来依赖，明确延迟或因果输入对照；之后再讨论实时/在线结论。
5. 固定数据、配置、候选权重及评价口径后，再做独立 test、独占时延和闭环实验。本轮未使用 test 选择方案。
