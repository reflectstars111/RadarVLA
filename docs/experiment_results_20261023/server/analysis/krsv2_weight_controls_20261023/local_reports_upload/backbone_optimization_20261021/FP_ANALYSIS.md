# 已有 T-RODNet 模型误报诊断

后续只读审计已完成：第5轮1720/1771个FP来自按原生损失规则不受objectness监督的候选，直接logit梯度为0，且这1720个框全部跨界；原始1472帧未发现应保留的运动车辆漏标。581个真实跨界目标中200个正确检出。详见 [边界专项审计](../boundary_audit_20261021/REPORT.md)。下文保留初次诊断的统计与当时的待验证假设。

对象：原始学习率3e-4、真实batch=1的T-RODNet，第3/5轮权重；完整验证集1472帧、2597个运动车辆标注。不是当前四组新训练的结果。没有评估测试集、修改权重或改变主要评估口径。

**最重要的发现：第5轮1702/1771个计分误报，其预测中心位于雷达50m监督范围之外，占96.1%。它们的预测框仍与监督区域相交，因此按当前规则被计为FP。误报增加主要发生在50m边界，不能直接解释为整个已标注范围内的背景识别都变差。**

## 位置拆解：关键线索是50m边界

使用每帧实际雷达安装位置，重新计算预测中心距雷达的水平距离；不是直接使用自车原点距离。验证集雷达前向偏移约1.49–1.62m。

| 计分FP预测中心距雷达 | 第3轮 | 第5轮 |
| --- | ---: | ---: |
| <48m | 166 | 39 |
| 48–50m，包含50m | 15 | 30 |
| >50–52m | 853 | 1535 |
| >52m | 112 | 167 |
| 合计 | 1146 | 1771 |

第5轮误报中心距离中位数50.74m，最大52.68m。第3轮监督半径内FP为181个、第5轮69个；中心在半径外且预测框与监督区域相交的FP则965→1702，增加737个。这解释了总FP净增625个的来源。

这里的“半径内”只是补充几何分层，不是新的主要评分口径。不能为了减少FP直接删掉这些框，也不能假定它们都是真实未标注目标。阈值0.5结果已逐项复现原训练的TP/FP/FN。

## 从源码得到的待验证假设

1. 输入保留约118m雷达范围。
2. `losses.py` 使用 `annotation_domain_mask(assignment_centers, batch)` 判断哪些anchor可以接受背景监督；范围外未匹配候选不作为负样本，已匹配边界正样本仍保留。
3. `detection_metrics.py` 对未匹配预测使用 `box_intersects_annotation_domain(...)` 判断是否计分；预测中心即使在50m外，只要预测框与监督区域相交，仍计入FP。

因此存在一个明确需要核对的差异：**训练背景覆盖看anchor中心，评估覆盖看预测框相交。** 边界外缺乏直接负样本监督的候选，有可能产生跨界预测并被计为FP；范围内anchor的预测偏移也可能跨界。

现有统计还没有保存每个FP对应的原始候选索引、anchor、预测框尺寸和objectness监督mask，故尚不能断言全部1702个FP都是上述机制导致，也不能据此决定应该扩大负样本范围或更改评估规则。

## 与静止车、重复框的关联

第5轮阈值0.5下：1651个FP未关联到已知目标；73个靠近静止车辆；41个靠近已匹配运动目标、可能为重复框；6个靠近骑行者。背景关联采用GT旋转框外扩1m的启发式规则，并优先标记2m内运动目标重复响应。

这说明“把静止车当运动目标”或“NMS不够强”没有解释大多数FP。但“未关联”不能直接等同于雷达噪声；还可能包含未完整标注区域的真实回波、定位偏移、道路设施等，需要原始雷达和框回放区分。

## 下一步应验证什么

保留正在运行的四组受控训练，先完成结果对照。优先追加只读边界审计：在同一前向结果中记录候选索引、anchor坐标、预测中心/框、置信度、是否参与objectness监督及正负标签，分别统计范围内anchor、范围外未监督anchor贡献的FP，并回放边界样本。

确定错误环节后再选择数据标注范围、候选输出范围或边界监督方式的修改；所有方案必须保留边界真实目标，并同时报告TP、FN、危险目标召回、运动误差和Risk，不靠改变计分规则宣称训练进步。

当前第5轮TP从1033降至670、召回从39.8%降至25.8%仍是真实退化，需要与边界误报分开诊断。检测解码阈值不改变直接从雷达特征预测的Risk输出，降低FP不等于已经改善五维风险。
