# 50m边界候选监督与误报审计

**结论：大部分误报确实与边界有关。已定位到的是“未受objectness监督的范围外候选生成跨界预测框，而评估将其计为FP”的接口差异；没有发现大量半内半外真实运动车辆漏标。跨界本身也不会把真实目标全部判为误报。**

本次只读检查原T-RODNet第3/5轮，完整验证集1472帧、2597个运动车辆实例；不是正在运行的新训练结果。使用原解码阈值0.5、NMS=0.3、中心匹配容差2m。重新推理后TP/FP/FN逐项复现原结果。没有执行优化器更新，也没有改变原项目、独立骨干分支或当前训练。

## 1. 核心证据：97.1%的FP来自无直接监督候选

逐个恢复解码预测对应的原始候选索引，记录anchor、预测框及原生损失的Hungarian匹配；对detach后的输出logit调用原生损失求导。它测量的是当前训练规则在验证样本上给出的 `d(objectness loss)/d(logit)`，不是对验证集训练，也不等于整个共享骨干的梯度为零。

| 指标 | 第3轮 | 第5轮 |
| --- | ---: | ---: |
| 计分FP总数 | 1146 | 1771 |
| 当前规则不监督的候选所产生的FP | 959（83.7%） | **1720（97.1%）** |
| 上述FP的直接objectness梯度为0 | 959/959 | **1720/1720** |
| 上述FP的预测框跨越监督边界 | 959/959 | **1720/1720** |
| 接受负例监督的候选所产生的FP | 165 | 37 |
| 接受正例监督但预测未匹配GT的FP | 22 | 14 |

第5轮这1720个无监督FP只来自检测网格距离维的第27、28行（从0编号）：1505、215个。预测中心相对anchor偏移中位数0.56m，框长/宽中位数3.46m/1.49m；并非主要由巨大异常框跨入监督区域造成。

这里的“无监督”是该帧该候选不参与objectness损失，不表示整个网络没训练过，也不表示共享卷积参数不会受到其他位置的梯度影响。此结果确认了边界机制，但修复后效果仍需独立对照证明。

## 2. 标注回查：没有发现漏掉的边界运动车辆

从全部1472帧原始 `frame.json` 的世界坐标actor快照重做原采集器几何判定，沿用当前moving-v1车辆类别和速度≥0.1m/s筛选，再逐ID对比manifest。

| 检查 | 数量 |
| --- | ---: |
| 原采集器应保留却未进入manifest的运动车辆 | **0** |
| manifest多出的运动车辆 | **0** |
| BEV框与监督扇区相交却未进入manifest的原始运动车辆 | **0** |

这是针对当前运动车辆任务的检查。静止车、行人、自行车按现有数据协议是背景，不属于本表应补回的正例。

第5轮1771个FP中，1698个附近2m内没有原始运动车辆中心；41个靠近已存在的GT；32个靠近原始快照中完全位于监督区域外的运动车辆。不能把这些关联直接当成雷达回波的物理归因，但它们不支持“大量正确边界检测因为漏标而被误判”的解释。

## 3. 半内半外的真实目标能否被计为TP？能

按当前标定与原生batch几何检查：

| GT几何类别 | GT数量 | 第3轮检出 | 第5轮检出 |
| --- | ---: | ---: | ---: |
| 框完全在监督扇区内 | 2015 | 793（39.4%） | 469（23.3%） |
| 框跨越监督边界 | **581** | **239（41.1%）** | **200（34.4%）** |
| 原标注保留、按当前浮点BEV框检查不相交 | 1 | 1 | 1 |

所有GT均按原规则保留；没有为了审计删掉最后一类。原采集器采用3D包围框采样/FOV判定，审计与评估采用标定后的二维BEV扇区，两者不强行视为完全同一几何定义。

263个GT中心在监督扇区外；第5轮至少120个中心在域外、但框跨界的真实目标正确检出。跨界目标整体检出率也没有低于完全在域内的目标。因此不能说“半内半外导致识别全部误报”。

## 4. 最小复现与源码对应关系

CPU上的最小原生调用复现重复运行一致：

1. 雷达原点为0，anchor在50.5m，预测4m长框跨入50m边界，无GT：该候选objectness梯度为0，原生评估FP=1。
2. 同一位置加入真实边界GT：原生分配保留正监督，梯度为负（推动置信度上升），原生评估TP=1、FP=0。

真实样本smoke也验证解码候选索引映射与原生mask/梯度一致；两个完整epoch审计分别在1472帧上验证。

源码关系：

- `src/losses.py`：背景监督使用 `annotation_domain_mask(assignment_centers, batch)`，即anchor中心；已匹配正例覆盖这一背景mask限制。
- `src/detection_metrics.py`：先匹配真实GT，之后未匹配预测只要 `box_intersects_annotation_domain(...)` 为真就计入FP。
- `src/detection.py`：原解码对所有候选做置信筛选/NMS，没有先限制到接受监督的anchor。

因此边界外候选可能没有直接负例抑制，却生成正常车大小的跨界框并被计分。新增误报主要发生在这个环节，不能简单归咎于T-RODNet没有学会所有域内目标，也不能通过调整报告口径把FP删掉。

## 5. 后续修改应满足的条件

下一步适合在独立实验中验证“候选训练范围与输出范围一致”的方案，同时保留边界GT。例如：把边界GT分配到域内有效anchor，利用中心偏移回归覆盖半内半外目标；推理解码使用相同的有效anchor范围。需要在配置与checkpoint中记录这一契约，并重新训练比较。

**不能直接对旧模型删掉全部未监督候选。** 第5轮670个TP中有46个也来自按该帧规则不受监督的候选，直接删除会损失现有真阳性；训练分配与推理解码必须一起设计，并检查NMS前后的影响。

当前四组优化训练保持原样，仍可作为同一旧契约下的受控对照。新契约实验需要固定数据、训练预算、阈值，报告完整TP/FP/FN、跨界目标召回、危险目标召回、运动误差和五维Risk。边界问题不能解释全部性能下降：第3→5轮完全域内GT检出也从793降到469，需要继续独立分析泛化与特征学习。
