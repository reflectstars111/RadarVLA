# KRS-v2五维损失与梯度检查，以及单变量权重对照

日期：2026-10-22。状态：检查完成，已确定两个独立对照；本阶段只读日志，没有启动新训练或修改原模型。

## 结论与证据强度

权重失衡是值得优先验证的假设。当前证据最支持先比较 **dmin权重1→0.25**，再独立比较 **areq权重1→3**。不是将两项一起改，也不整体放大Risk权重。

这不是证明权重就是泛化根因：分项loss不具备天然可比单位；梯度探针有采样偏差且只有范数、没有方向；验证短时正例集中在一个episode。本报告据此设计可证伪对照，不声称已找到最优权重。

## 审计范围与完整性

- 基线：新KRS规格，T-RODNet从头训练20轮，seed42，batch4/累积2，LR2e-4。
- 读取完整34,340个训练batch，以及144个记录共享特征梯度的batch；每轮1717个batch、6868个不重复样本。
- 每轮三个冲突窗口正例数均为31/52/144，正制动需求标签有效样本为120；没有发现训练样本遗漏、重复，或正例计数与manifest不一致。
- 逐batch核对分维Focal之和等于原collision项，加权分项之和等于训练总loss；核对通过。
- 每轮五维有效标签计数：{'pcol0.5': 6868, 'pcol1': 6868, 'pcol2': 6868, 'dmin': 5529, 'areq': 5505}。
- 每份原始训练日志SHA256保存在analysis.json，用于追溯；测试集未读取用于调权重。

## 五维权重到底是什么

当前配置中collision、distance、brake组系数均为1。但前三维在所有有效冲突标签上一起取平均；当前每批12个冲突标签都有效。因此每个冲突维度相当于占该三维均值的1/3。

距离先除以10m，制动需求先除以5m/s²，再计算Huber；单调项系数0.1。以下是**实际训练目标中的贡献**，不能把归一化后的数值直接当物理误差，也不能理解为五个任务重要性应由loss大小决定。

## 与验证现象相互核对

第20轮正制动需求验证样本只有12个，其areq MAE为1.4976m/s²，而零制动需求1205个样本的MAE仅0.01054m/s²。危险dmin样本22个，MAE为1.0473m。不能用总体MAE掩盖这两个子集。

短时AP并未随训练loss单调下降而一直改善：第12轮AP0.5/AP1为0.5344/0.5880，第20轮降为0.3877/0.4956；AP2第16轮为0.8195，第20轮为0.7313。因此不能仅凭训练loss小就继续加轮次，也不能仅凭本报告的loss占比宣判权重是唯一原因。

## 确定的单变量对照

下面的向量按 `[P0.5,P1,P2,dmin,areq]` 表示**对原有分项的额外乘数**；前三维原有共享均值分母不变，不将整组系数归一化到和为1。

| 组别 | 乘数 | 唯一改变 | 验证问题 |
| --- | --- | --- | --- |
| C0：已完成基线 | `[1,1,1,1,1]` | 无 | 共同参照 |
| A：第一优先 | `[1,1,1,0.25,1]` | 原生distance系数1→0.25 | 减弱常见距离回归的相对影响，是否改善短时Risk平衡且保持危险距离质量？ |
| B：独立第二组 | `[1,1,1,1,3]` | 原生brake系数1→3 | 保留距离学习，单独增加制动分支贡献是否降低正制动需求误差？ |

若仅对当前模型的已记录分项作代数重加权，A中第20轮dmin占Risk约从81%变为52%，仍不是移除距离任务。在有正制动需求的后期探针上，A/B会分别把areq/dmin范数比中位数从0.290变为约1.16/0.87。这些是固定输出上的算术关系，不是重训后的效果预测；Risk总梯度不能根据单项范数直接相加推算。

## 公平实施与比较规则

1. 两组都从seed42重新初始化，各20轮；沿用原batch、LR及调度。B不从A的权重继续训练，也不从已完成基线的epoch20继续，否则训练预算和初始状态会混杂。
2. 只改一个原生loss系数。保留归一化尺度10/5、Focal、单调项0.1、全部检测/运动系数、mask、采样器、标签、候选、NMS和模型结构。
3. 新运行需记录加权后的五维梯度及Risk/Detection分解；不能用仅适用于系数1的旧observer计算改变权重后的总Risk梯度。先测试单位乘数复现原loss/梯度，再启动。
4. 主要对比固定epoch20；epoch12、16作为预先固定的次要对比点，完整曲线全部保留。不各自挑不同的最高AP轮次来声称胜出，不只按val总loss选模型——改变权重后总loss本就不可直接横比。
5. A检查三个窗口AP/Brier、误报/危险召回，同时守住危险dmin误差；B以areq>0子集MAE为目标，同时检查零需求误差、AP/Brier、检测和运动。
6. 运动误差同时报告原生匹配ADE/FDE及匹配数量，并在共同GT目标匹配交集上比较；防止靠漏掉难目标让ADE变小。
7. 目标项改善且其他关键项不退化才作为整体改进候选；若有取舍，明确记录，不自动宣布胜出。不靠查看test改权重。

三seed仍按用户要求暂缓。单seed CUDA反向存在已记录的非确定性，不能保证逐步完全一致；较小差异只能视为探索性结果。0.5/1秒val正例各只来自一个episode，也不能据此宣称跨场景泛化已解决。
