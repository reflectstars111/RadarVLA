# RadarVLA：Pcol³ˢ教师覆盖补充实验

本实验检验：让缺失其他风险维度的样本也参与模式蒸馏，能否使预测风险更接近 Oracle 的决策效果。

## 对照与解释边界

- 训练集477个Pcol³ˢ正例中，191个缺少完整五维标签，占40.0%。此前这些样本仍参与有效维度的物理监督，但不参与完整GT风险教师的KL。
- 新教师仅把原模型的Pcol³ˢ替换为真实标签；Pcol¹ˢ、Pcol²ˢ、dmin和areq仍为原模型预测。这是混合风险干预，不能称为完整真实风险。
- KL现在覆盖所有Pcol³ˢ有效训练样本。教师固定、stop-gradient；Student只接收雷达和自车特征，不接收真实风险。
- 同一起点、缓存、训练顺序、3epoch、batch8、lr0.0003、seed42、KL权重1、温度1；仅25285个风险参数可更新。最后一轮为预先指定结果，没有按验证集选轮次。
- 相比完整GT风险教师，教师内容和监督覆盖同时改变，因此本对照不能独立识别覆盖率的因果作用。
- SHORT/LONG真值来自现有Local风险规则（Pcol1/2、最小间距和制动需求），并非独立人工安全评定。本批Pcol3干预与这些标签高度一致，不代表一般场景仅需Pcol3即可规划。

## 判断

扩大Pcol3教师监督后，SHORT召回没有超过仅物理监督。当前短预算结果不支持将这套蒸馏方案作为真实风险的有效替代。
Pcol3教师学生的SHORT召回为23.9%，仅物理监督为23.9%；误报分别为39和26。完整GT风险Oracle仍为95.7%。
按10个episode配对bootstrap，召回差95%区间为[0.0, 0.0]，LONG误报率差区间为[0.003007682050699442, 0.023735531925027975]。只有一个seed和短训练预算，不能外推为所有训练设置均无效。
本对照是否值得后续投入，要同时看召回、误报和物理风险误差；不能仅凭AP提升便声称取得了真实风险的效果。没有自动替换默认模型。
这里完成的是全验证集风险与首个BOS模式评价，没有进行完整自由轨迹rollout或闭环测试，也没有使用test集。
