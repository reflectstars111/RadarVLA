# RadarVLA 危险漏检与Risk泛化诊断

日期：2026-10-22。第一阶段诊断已完成；核心识别效果尚未修复，新规格正式训练保持暂停。本轮没有修改主源码、标签或原模型权重。

## 最重要的结论

目前至少有两条不同的误差路径：危险目标候选置信度不足，以及可用运动/几何信息没有稳定转化为Risk。还有一个被整体均值掩盖的问题：正制动需求样本的回归误差很大。

证据支持优先做危险子集的检测置信度学习、显式运动几何与Risk融合，以及制动分支监督的受控对照。没有证据支持直接把问题归因于YOLO位置头、NMS、五维梯度相互抵消，或认定换一个MLP即可解决。

## 三、29个危险目标漏检主要卡在置信度

所有29个漏检都能在有效候选范围内找到预测中心距GT不超过2m的候选，但最佳置信度低于0.5；本批未归因于候选中心无法接近目标或NMS。

26个“漏检且Risk低”的子集：

- 2m内最佳有效候选置信度中位数：0.140。
- 按训练规则分配的候选置信度中位数：0.021。
- 分配候选预测中心误差中位数：0.570m。
- GT框内有效Doppler且Power>0的格点数中位数：48；框内/周围2m环带平均功率比中位数约9.60dB。
- 雷达关联径向速度与GT投影的绝对差中位数约0.069m/s。

这些信号审计使用GT框定位，属于特权诊断，并不证明每个反射都能无歧义归属该车。但它们说明不能把这批漏检全部归因于无回波/无运动信息。当前结果也不支持先改NMS或继续扩大检测目标数量。

## 四、部分预测运动已经足够判险，但Risk没有利用好

几何对照使用全部解码预测，包括误报，不做GT匹配筛选；只读取当前ego速度/转向率/尺寸以及模型预测的框、运动和未来轨迹。没有GT Actor位置、速度、未来轨迹输入。

- test的20个“目标检出、P3低”样本：预测轨迹几何识别14个冲突；预测当前状态CV识别15个。
- test的26个“漏检、P3低”样本：两种几何均识别0个，说明仅依赖解码框的Risk会继承检测漏检。
- test的57个同场景安全对照：预测轨迹几何报告3个冲突；学习Risk在0.5工作点报告1个。
- val的18个“检出、P3低”样本：预测轨迹几何识别6个；35个安全对照上报告6个冲突。

安全对照是邻近时间的诊断子集，不能把其误报比例当作完整val/test误报率。几何结果是预测状态下的二值推演，不是校准概率；假设预测heading固定，也不能视作连续时间安全保证。

因此合理方向是保留Radar风险路径，加入带置信度与运动不确定性的几何信息；不能用规则直接替代Risk，也不能硬性只对已解码目标计算风险。

## 五、五维Risk的误差并不同步

旧test：总体 areq MAE=0.0677m/s²；48个有效且确实需要制动的样本 MAE=1.5154m/s²，预测中位数=0.005490m/s²，26/48低于0.01。1156个真实areq=0样本的MAE仅0.0075m/s²，主导了总体平均值。

另外9个危险样本的areq mask为false：8个已经处于危险贴近状态，1个无可行制动减速度。不得将这些mask为false的数值当作0制动需求监督。

旧test危险57帧 dmin MAE=5.2696m，预测中位数3.6665m而真值中位数为0；非危险有效样本dmin MAE=2.7915m。风险子集的高估不能被总体回归均值掩盖。

15个代表帧的分项梯度通过FP32规范loss求和检查。Pcol3梯度能到达encoder feature、位置编码后的KV和Radar tokens，并非Risk梯度完全断开。共享MLP第一层中Pcol3与dmin梯度余弦全部为正；与areq在14/15帧为正、1帧为负。本样本证据不支持普遍梯度互相抵消的结论。

部分areq输出接近零，其梯度明显弱于冲突/距离分支。当前输出采用Softplus，接近零时对raw输出的导数也接近零；这是需要对照验证的优化瓶颈，尚不能断言它单独导致了泛化缺口。梯度分项必须看真值、mask和输出尺度，不能只比较loss数值。

## 六、训练延长与场景组成

原先0.467→0.218、0.552→0.442来自20轮筛选任务与另一个40轮任务；不能严格当作同一训练路径。

同一个40轮任务的验证历史：

| 时间窗口 | epoch20 AP | epoch40 AP |
| --- | ---: | ---: |
| 1s | 0.4506 | 0.2180 |
| 2s | 0.6672 | 0.4423 |
| 3s | 0.6822 | 0.6738 |

三个时间尺度均下降，短时更明显。不能据此仅凭单seed、极少正例就宣判过拟合，但足以否定继续训练必然受益。

val危险35帧来自3个episode，test危险57帧同样来自3个episode；test其中29帧集中在scenario3 episode。该episode AP3约0.187，scenario10 episode约0.124，scenario2 episode约0.840，存在明显场景差异。旧val1秒正例仅5帧/1个episode，任何1秒改动的验证结论都很脆弱。

新版重划分解决了0.5秒val空正例，但0.5秒事件总体仍只来自3个episode，每个集合各1个。重新划分或反复采样不能增加独立场景多样性。
