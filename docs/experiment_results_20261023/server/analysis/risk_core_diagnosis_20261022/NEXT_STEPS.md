# 旧协议受控修复优先，新规格正式训练暂停

当前状态：诊断完成，尚无通过联合验收的修复候选。仅完成冻结模型的小型读出对照，不将其作为部署效果。

## 1. 固定基线与验收信号

使用旧moving-v1 manifest、旧1/2/3秒配置、固定seed42及原checkpoint作为共同起点；所有修改在独立worktree。保留原数据划分与已有结果，不把新val已经见过的旧权重当作新划分泛化基线。

验证同时记录：危险目标召回及漏检阶段；全场景误报；固定检测匹配集上的速度/轨迹误差；各风险窗口AP、Brier与正例召回；危险子集dmin高估；areq>0子集MAE及近零塌陷比例；按episode列出变化。阈值/权重只能在train/val设计，旧test仅保留为已诊断材料。

## 2. 先做危险目标置信度学习的单变量对照

本批29个漏检都属于位置候选存在但objectness不足。第一组只改变训练侧危险样本/目标的曝光或正例权重，保留候选、解码阈值、NMS和目标数量。优先核对训练中危险对象的分配候选实际得到多少正梯度、与同场景易检出对象有何差异。

如果提高危险召回却显著增加背景误报，不接受为修复；不能仅降test阈值。重采样要以episode/event为单位控制重复，记录有效先验变化，避免把连续帧当独立新场景。

## 3. 再做Motion/Geometry→Risk的单变量对照

保留原Radar Risk通路，附加由模型预测位置、速度、框尺寸、未来轨迹和置信度形成的可解释几何特征。不要只对高置信检测算Risk；要保留未检出目标的雷达证据路径和覆盖不确定性。预测Actor不能经GT匹配过滤，也不能替换成GT状态。

先冻结Grounder验证读出/融合，再考虑解冻少量聚合层；同时看短时AP、Brier及几何误报。现有固定小读出只改善2/3秒AP，1秒和校准未改善，尚不满足启动正式新规格训练的条件。

## 4. 单独处理制动需求分支

先核对areq>0的训练曝光、loss归一化、Softplus raw梯度及mask，再比较提高正制动需求监督与适配原0.5m/s²离散网格的分类/序数辅助头。旧标量五维输出可保留，但不可把无可行减速或当前危险贴近的mask=false样本强制监督为0。

必须报告正制动需求子集，禁止只凭总体areq MAE接受结果。拆分概率和幅度/离散网格仅作为待验证候选，不预设优于原方案。

## 5. 数据和模型选择

补充独立危险episode，尤其0.5/1秒近冲突和scenario3/scenario10覆盖。优先保证事件多样性，避免只复制31帧或13帧。

检查点选择同时约束短时Risk与检测/运动/正制动需求表现；不允许只取最高AP3或总体F1。采用预先声明的验证误报预算和跨episode对照，容差按基线测量噪声记录，不在看过test后制定获胜阈值。

## 6. 之后才进入新KRS训练

在旧协议小规模受控修复得到联合改善后，迁移设计到独立KRS-v2 worktree，从头训练0.5/1/2秒风险与2秒dmin/areq。使用已验收的新manifest与匹配配置，保留原源代码/数据/权重以便回退。三seed验证仍按用户要求暂缓，不自动启动100轮训练。

新的正式训练未排队，也无后台自动启动器。下一阶段是验证上述修复候选，不能把本报告解释为问题已经解决。
