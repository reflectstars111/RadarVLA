# RadarVLA 风险输入修改：最终报告

日期：2026-10-19（Asia/Shanghai）。本轮完成输入核查、Oracle完整rollout、低速拆解、三组一轮训练控制，并实现累计风险概率一致性的显式实验开关。

接线核查未发现错误。保序输入消除了158帧累计概率矛盾，但模式不变，共同点ADE反而增加0.0109m。因此不推荐在当前checkpoint上默认启用；旧none配置与原模型保留。风险预测准确性尚未修好，这一轮不能宣称规划改进。

## 1. 实际修改

- `src/risk_state.py`：增加无参数、可反传的三点isotonic投影，将概率投影到 `P1≤P2≤P3`；不读取GT，不拟合校准器，不改变dmin/areq或其单位。
- Tiny/HF Planner共享 `condition_risk`，在单位归一化之前应用修正，确保实际送入LLM的Risk一致。
- 新增训练配置 `configs/l40s_qwen25_3b_taskwise_local_isotonic_v1.json`；推理/评价可显式指定 `--risk-projection isotonic`。旧checkpoint缺少该字段时默认none，保留原始行为，避免默默改变已记录的实验。
- 导出同时保留原始 `risk`、实际 `conditioning_risk` 和 `risk_projection`，区分估计器输出与规划器输入。评价中的常规Risk指标仍是Grounder原始输出，投影对照指标在本报告另列。
- `--freeze-grounder`、`--detach-risk-condition`及其匹配训练对照已实现和验证，详情见 [控制实验报告](IMPLEMENTATION_REPORT.md)。

## 3. 前三步结论

- 接线核查未发现Local/Global混用、五维顺序错位或重复归一化；真实问题包括预测质量及累计概率不一致。
- 1407帧完整Risk cohort中，GT Risk使模式召回21.7%→95.7%，共同点ADE1.1558→1.1650m。改善模式不等于改善轨迹。
- 823帧真实未来基本静止样本，最大预测位移均值1.873m；232次离线冲突在固定朝向探针下仍存在，停车漂移不能只归于朝向近似。
- 同一823帧静止样本，GT编码/解码的逐场景要求点ADE均值0.0955m，teacher forcing为0.1487m，自由生成为0.7213m；近零单轴分箱中心为±0.0722m。量化有误差底限，但不能单独解释自由生成漂移。这些ADE按场景等权、各条件自身已覆盖要求点计算，并非共同点配对指标；不能与上表按时间点加权的ADE混用，也不把缺失点计零。
- Risk标签基于当前速度/转率的nominal Ego轨迹，而非随后生成的任意计划；正确nominal Risk不是候选计划的安全证书。
- 三组训练是同初始化、同有效batch8、同seed42的一轮短预算控制；与原5epoch候选不直接比较。其全部指标和GT世界前缀拆解见 [完整修改与控制报告](IMPLEMENTATION_REPORT.md)。

一轮控制的实测差异（以下只与新joint一轮基线比较）：

- frozen：Pcol³ˢ AP 0.1154→0.1612，Brier 0.0400→0.0556；SHORT召回0.0%→0.0%，LONG误报0→0帧。
- detached：Pcol³ˢ AP 0.1154→0.1099，Brier 0.0400→0.0401；SHORT召回0.0%→0.0%，LONG误报0→0帧。

一轮结果只提供后续假设的筛选证据；不能将其中一个模式指标变化称为已修复风险，三个新候选尚未跑全量自由轨迹。

低速前缀拆解中，选择的83帧静止诊断样本，共同点ADE为自由生成1.5566m、仅GT模式1.5566m、GT世界前缀0.4767m。该选择含最差误差样本，不能当作总体均值；GT前缀同时包含他车未来与道路信息，结果证明条件敏感性，不能单独证明某种感知错误或训练暴露偏差。

## 4. 使用与后续判断

新增isotonic配置仅供后续一致性训练对照，本轮尚未训练这一配置；当前checkpoint的完整验证出现ADE增加，因此默认继续none。下列开关只用于复现离线对照，不能作为已验证有效的默认设置：

```bash
python -m radar_vla predict --checkpoint <checkpoint.pt> --manifest <manifest.jsonl> \
  --split val --output <predictions.jsonl> --device cuda:0 --batch-size 1 \
  --risk-projection isotonic
```

主路径仍然使用预测Risk。真实标签只用于诊断，原checkpoint和数据未覆盖。新算子处理物理一致性；碰撞概率的校准、稀有危险场景召回和停车轨迹保持仍需分别验证，不能用这项修正替代后续训练。

下一轮应把两个假设分开：风险/模式分支检查稀有正例与类别不平衡（权重只能由train统计，不在val拟合）；停车侧检查生成他车/道路前缀条件下的自车监督对照。已有Ego状态与初速损失，无需重复添加；也不应把全部低速车辆强制停车。先固定预算改变一个变量，再评价完整轨迹覆盖与共同点误差。
