# RadarVLA：漏检样本的输入、特征与梯度诊断

**结论：原始输入中多数漏检目标有可用径向证据；共享感知栈的泛化、检测置信度与运动预测应优先验证。** 36个漏检帧中35帧有危险来源的有效Doppler单元；冻结token探针训练AP约0.95–0.97、验证AP约0.43–0.50；检测来源目标仅20/37检出。当前证据尚不能把责任单独归到卷积Encoder或8-token压缩，诊断池化对照已排除直接比较不同空间摘要的错误归因。

本轮定位风险估计误差出现的位置，没有修改风险定义、训练目标或部署模型。所有可读性探针独立于原模型，不把其分类结果计作Planner模式提升。

## 范围与可复现性

- 原模型完整标签子集：{'miss': 36, 'hit': 10, 'false_alarm': 17, 'safe': 1344}；其中36个漏检分布于3个episode，完整GT风险可恢复其中34帧。
- 输入/梯度详细回放99帧：全部漏检、全部命中、全部误报，加36个同episode、近似自车速度及最近目标距离的安全对照。相邻帧相关，不能视为同等数量独立场景。
- 全训练集6728帧用于缓存特征探针和梯度统计。压缩前后的配对探针用1477帧训练子集（全部477个Pcol3正例+seed42抽取1000个负例），验证集始终1461帧；Risk与8+1个token共2938帧原始输入重放逐位匹配原缓存。train/val的episode不相交；test未用于拟合或评价。
- 模型处于eval，只有梯度读取，没有优化器更新；全部Grounder权重及缓冲区逐位不变。未加载Planner模型，未跑轨迹rollout。
- 单GPU、单CPU线程、nice19/ionice3，显存配额12%，启动需32GiB空闲；低于8GiB空闲时仅本进程退出。

## 假设1：危险来源目标在原始输入中是否有证据

用GT当前框归属回波仅用于诊断，不是推理输入。正功率且Doppler有效不等于已确认可辨识目标：雷达噪声、背景和混合反射也会满足条件；因此同时报告径向速度误差及相邻2m环带的功率对比，后者不是校准SNR。
来源目标归属表仅针对最后一帧。动态目标在历史帧的位置需要同步历史轨迹，不能用当前框替代；当前未覆盖不能直接推出四帧输入均不可见。各级特征及探针使用完整四帧输入。

漏检36帧中，使用GT当前位置/速度、对他车作恒速推演即可判为3秒冲突的有20帧；危险来源真实3秒位置偏离当前恒速外推的中位数为0.010m。这个对照使用特权当前状态，说明运动假设的作用，不能证明网络从雷达已恢复了这些状态。

## 探针自身的池化与非线性对照

主探针中raw_grid保留8×8，而CNN/KV取2×2空间摘要。这是诊断读出的差异，不是网络中真实的前后层等价比较。补充把原始输入也池化2×2，并给CNN/KV加同样64隐层MLP，保持1477训练帧、1461验证帧及训练预算不变。

| 读取方式 | 验证AP最小值 | 验证AP最大值 |
| --- | --- | --- |
| raw2_linear | 0.0765 | 0.0773 |
| raw2_mlp | 0.0743 | 0.1320 |
| raw8_mlp | 0.2264 | 0.2846 |
| cnn2_mlp | 0.1548 | 0.1807 |
| kv2_mlp | 0.0597 | 0.1304 |

原始输入2×2线性探针AP约0.077，低于CNN2×2线性探针约0.109–0.116。因而不能用原始8×8与CNN2×2的AP落差直接证明卷积Encoder破坏了信息；空间摘要本身已带来强烈影响。添加非线性读出也未消除训练/验证差距。当前证据支持感知栈泛化不足，尚未精确区分卷积骨干、池化和8-token压缩的因果责任。

## 共享Encoder与检测头专项结论

36个风险漏检帧对应37个危险来源目标，检测头检出20个，另17个均在低置信度关口丢失；已检出目标的速度向量误差中位数2.14m/s、未来ADE中位数2.27m。同一20个目标原始关联径向速度误差中位数约0.020m/s，检测预测误差约0.728m/s。
这些结果支持优先排查共享感知/运动学习与检测置信度。Risk读取共享token，检测框不直接进入Risk；因此既不能把检测漏检等同风险的直接输入缺失，也不能通过本轮探针单独认定三层CNN就是唯一根因。
[完整检测头专项报告](detector_audit/REPORT.md)包含架构、候选框丢失阶段、运动误差以及共享Encoder梯度。

## 证据边界与下一步

本报告用于区分输入证据、表征可读性和局部学习信号，尚未证明单一原因。需要结合上表中的危险来源回波质量、跨episode探针结果、正负样本梯度及其冲突，再决定修改哪一层。尚未进行模型修复，也未宣称风险或轨迹指标提升。
