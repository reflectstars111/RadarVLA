## 6. 证据范围与复核入口

- 单seed实验，不能据此宣称统计显著；按用户要求未新增三seed训练。
- 初始化审计发现Risk SFT与等预算baseline readout对照的planner初始可训练权重SHA256不同。相同seed不等于相同初始权重，本轮SFT差异不能完全归因于Risk输入。原始记录见INITIALIZATION_AUDIT.json；这不影响已完成指标的真实性，但限制单变量因果解释。
- 常规误差、共同点误差、危险场景误差、覆盖率和碰撞可评分母必须联合判断，不能凭单个ADE或AP挑选骨干/方案。
- 轨迹范围仍为3秒，KRS为0.5/1/2秒、几何窗口2秒；二者没有混同。
- 当前仍使用既有离线双向预处理数据，不宣称严格在线因果性或闭环安全。
- 共享GPU时的时延受节流及其他任务影响，本报告不据其宣称独占性能。
