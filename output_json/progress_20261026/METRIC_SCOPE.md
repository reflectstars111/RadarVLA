# 本轮评估口径

- “完整”指validation1451帧和test1522帧逐帧评估，不再使用训练时32帧的模式平衡子集。
- 使用原生动作优先推理接口。parallel action模型直接生成ego动作及mode，本轮不另外运行其可选文字描述生成；不把该项结果称为完整文字描述或LLM他车控制点生成质量评估。
- 原生报告中的agent位置、速度、ADE/FDE与检测指标来自Grounder的目标预测。其中GT匹配物理误差与置信度/NMS后匹配误差是不同口径，不能互换。
- 常规ego ADE/FDE只统计有效且实际覆盖的点，SHORT缺失3秒终点不算成功。教师要求点覆盖、共同点配对误差、危险场景误差另列。
- baseline使用原训练选出的SFT第3轮best_planning，其他组使用第5轮。此选择在完整val/test开始之前已固定，不能把结果当作“所有组同为第5轮”的对照。
- Risk五维规格为0.5/1/2秒冲突概率、2秒d_min与a_req；ego轨迹仍预测3秒。原生物理碰撞按实际生成轨迹时域评分，TTC是另外的局部恒速几何量。
- parallel action的valid标记包含动作初始条件约束。initial_acceleration_exceeds_limit表示观测初始加速度超过8m/s²；该类无效不等于文本解析失败。原生报告同时保留初始速度误差、jerk等动力学指标。
- 固定0.5风险阈值只用于额外错误诊断，未利用test优化阈值。AP评价排序，不能替代指定阈值下的危险召回。
- 完整val/test的LONG/SHORT比例通常不等于训练期间32帧平衡子集，不能仅凭总体ADE变化声称模型提升。
