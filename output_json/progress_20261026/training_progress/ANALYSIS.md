# 阶段结果分析：2026-10-24 08:10

依据：服务器本轮五组完整 epoch 指标、配置、原生匹配诊断和共享调度代码；原始曲线保存于同目录 analysis_full_metrics.json。分析未读取 NAS 原始雷达、未更改运行中配置、未评估 test。

结论：baseline 仍是当前可靠参照。local_quality assignment 改善运动回归，但在固定推理阈值下严重损害目标检出；新增预测几何 Risk 输入没有超过等预算 readout 对照。总验证 loss 与任务指标的最优 epoch 明显不一致，末轮结果也不能代表模型上限。

## 1. Assignment 的主要代价是漏检

| 第20轮验证指标 | baseline | assignment |
|---|---:|---:|
| TP / FP / FN | 1621 / 275 / 2114 | 562 / 86 / 3173 |
| Precision | 85.50% | 86.73% |
| Recall | 43.40% | 15.05% |
| F1 | 0.576 | 0.256 |
| 速度 RMSE，m/s | 2.719 | 2.315 |
| GT 匹配轨迹 ADE，m | 4.154 | 3.467 |
| GT 匹配轨迹 FDE，m | 7.136 | 6.012 |

少了189个误报，却同时少检出1059个真实目标，precision 只增加1.23个百分点，recall 下降28.35个百分点。现有阈值下不能把它作为检测改进采用。

assignment 第2轮 recall=27.15%、F1=0.403；第3轮 recall=9.24%、F1=0.166。日志确认前两轮 local_quality_frames=0，第3轮开始每轮5529个含目标帧启用新匹配，其中90帧退回原始匹配（约1.63%）。突降与策略切换高度一致，优先检查匹配策略及 objectness 学习。低回退率说明绝大多数帧确实运行新策略；不能仅凭这些统计确认具体错误机制。

可能包括：正样本槽位随预测变化，回归好的候选未同步获得足够的 objectness，或置信度分布移动。需要同 checkpoint 的阈值扫描/PR、匹配稳定性及 TP/FN 分数诊断区分；现有统计不能断言是雷达缺失、边界裁剪或标签权重造成。

GT匹配的运动误差也下降，说明收益不完全来自“只保留容易检出的目标”。但这种物理匹配允许低置信度候选参与，不代表实际解码输出获得同样覆盖。只在通过检测的目标上计算的 matched ADE/FDE 更不能脱离召回率比较。

## 2. Risk 几何输入尚未显示新增价值

两个 readout 从同一个 baseline Grounding 第20轮初始化、冻结感知，各运行10轮。它们才是判断新增输入收益的主要受控对照。

| 第10轮 AP | 原 Risk 输入 readout | 新几何输入 readout | 新减旧 |
|---|---:|---:|---:|
| 0.5s | 0.59160 | 0.58956 | -0.00204 |
| 1s | 0.68137 | 0.68090 | -0.00047 |
| 2s | 0.77355 | 0.77311 | -0.00043 |

两组 d_min MAE 约6.59m、a_req MAE 约0.0179m/s²，也基本一致。没有证据支持“新增几何输入已经解决 Risk 泛化”。同样不能据此证明几何信息无用；应检查融合分支是否依赖几何、特征质量和有效梯度。

相对 baseline Grounding 末轮，原输入 readout 的2s AP从0.7529升至0.7735，但0.5s从0.6524降至0.5916，1s从0.7117降至0.6814。这是不同时间窗的取舍，不能表述为五维风险整体改善。单看两项 MAE 也无法认定五维损失权重错误，尤其 a_req 可能受到大量安全/低值样本主导，需要有效危险样本分组指标。

## 3. 选 checkpoint 是当前明确暴露的问题

| baseline 选择依据 | Epoch | F1 | 0.5s / 1s / 2s AP |
|---|---:|---:|---|
| 最低总验证 loss | 6 | 0.521 | 0.149 / 0.130 / 0.178 |
| 最高检测 F1 | 15 | 0.594 | 0.678 / 0.757 / 0.773 |
| 最高三窗平均 AP（事后描述） | 12 | 0.561 | 0.725 / 0.768 / 0.785 |
| 固定末轮 | 20 | 0.576 | 0.652 / 0.712 / 0.753 |

原生 best.pt 按总验证 loss 保存，best_detection.pt 按 F1 保存。总 loss 最小明显不等于 Risk 最好；训练loss从第6轮0.621降到第20轮0.097，而总验证loss从1.534升至2.860，存在泛化/多任务指标分离信号。不能因此说所有任务都在第6轮之后过拟合，因为 Risk AP 在之后显著改善。

assignment 第13轮三窗AP=0.581/0.754/0.858，2s比baseline末轮高，但其召回只有15.15%。这进一步说明检测与Risk共享特征却不是同一个指标，不能简单推断“目标漏检必然导致Risk低估”。该epoch为事后观察，不是已确认的最优可部署模型。

本次运行器固定从 Grounding epoch_020.pt 接 readout/SFT；不是误加载低loss的best.pt。保持本轮规则，避免中途改 checkpoint 使实验不再可比。下一轮应在验证集上预先规定联合选择规则，优先满足危险目标召回/短时风险要求，再比较运动与规划误差。

## 4. 数据量与结论范围

验证集1451帧，0.5/1/2秒正例分别13/15/22。个别正例的排序可明显改变AP，单次0.858不能视作稳定优势。全部结果是验证集、单seed；用户已取消三seed验证，本分析不将其重新加入当前队列。test尚未评估，也没有新的危险目标召回分组报告，因此不能与旧规格test的28/57直接比较。

## 5. 后续顺序

1. 保留既定SFT对照，等待ego ADE/FDE、有效轨迹率、模式与碰撞/风险分组指标；当前baseline/action/assignment已进入第1轮真实训练，尚无完整epoch验证结果，不能判断规划改进效果。
2. 优先补baseline/assignment现有checkpoint的同口径阈值/PR对照，区分objectness校准和实际可分性下降。阈值选择使用验证集，保持test封存。
3. 若降低阈值仍不能在可接受误报下恢复召回，再定位新匹配下正样本槽位稳定性、objectness与回归梯度，做单变量修复。
4. 对Risk几何分支补几何打乱/屏蔽敏感性和有效梯度、五维危险子集误差，确认模型是否利用该输入后再决定权重或聚合修改。

目前不支持单纯继续拉长训练或把combined直接设为默认方案。
